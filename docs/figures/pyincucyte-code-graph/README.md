# PyIncucyte automation code graph

This figure shows the supported path from Auto-Organotypic, direct Python calls, and
one-shot command-line runs to PyIncucyte's public package boundary, client,
watcher, engine, and typed result records.

The relationships were checked against the copied package modules and the
current Graphify report. The graph deliberately compresses the full code map:
arrows show the automation call and return path, not every Python import.

`figure_data.csv` contains every displayed node, edge, label, position, and
annotation. No inferential statistics are reported.
